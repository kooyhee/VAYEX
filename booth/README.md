# 국립목포해양대학교 공학작품경진대회 부스 운영자 카드 (Operator Card)

본 문서는 **2026학년도 컴퓨터공학과 공학작품경진대회**(팀명: 비용절감위원회) 부스 현장에서 **(B) 현장 실작업 세션(2~3분)**을 매끄럽게 진행하기 위한 1장 운영 매뉴얼이다.

---

## 1. 운영 환경 및 기동 절차

### 1.1 하네스 호스트 실행
- **실행 명령**: 프로젝트 루트에서 `launch.cmd` 또는 PowerShell:
  ```powershell
  .\launch.ps1
  ```
- **접속 주소**: 웹 브라우저에서 `http://127.0.0.1:4317` 접속 (작업 공간 단일 탭).
- **작업 디렉터리(Target Workspace)**:
  `<repo>\booth\sample-project`
- **미리보기 탭 준비**:
  별도 브라우저 탭(또는 분할 창)에 아래 파일을 열어 둔다:
  `file:///<repo>/booth/sample-project/index.html`

## 5. 원상복구(Reset) 절차

다음 방문자를 맞이하기 전 30초 이내에 예제 프로젝트를 깨끗한 원본 상태로 복구한다.

### 5.1 원클릭 복구 실행
- **CMD / 바로가기**:
  ```cmd
  booth\reset.cmd
  ```
- **PowerShell**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File booth\reset.ps1
  ```

### 5.2 복구 보장 메커니즘
- `booth/sample-project-pristine/` 원본을 바탕으로 `booth/sample-project/`를 바이트 단위로 100% 미러링 복원.
- 추가 생성된 임시 파일 자동 제거, 변경 파일 강제 덮어쓰기.
- Git 명령이나 외부 패키지 설치 없이 로컬에서 독립 동작 (측정 복구 시간: **1~2초**, 기준치 30초 대비 90% 이상 단축).
- 복구 완료 후 미리보기 브라우저 탭에서 `F5`(새로고침) 및 하네스 UI에서 `새 세션` 클릭.
