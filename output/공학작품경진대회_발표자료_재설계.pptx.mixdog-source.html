로컬 파일과 명령 실행 권한은 중앙에 부여하지 않는다. 요청에는 필요한 코드 발췌와 문맥이 포함될 수 있으며 선택된 모델 공급자에게 전달된다. SQLite FTS5는 검색 인덱스이며 실행 로그와 함께 메타데이터를 관리한다. 로컬 파일 체크포인트는 파일 상태 보존 및 복구 장치로, SQLite 인덱스나 로그와 별개다. API 응답 스트리밍은 요청의 응답 방향이며 양방향 SSE를 의미하지 않는다. 게이트웨이를 무상태로 단정하거나 코드가 절대 외부로 나가지 않는다고 주장하지 않는다. 출처: 사용자 최종 승인 문구 §04, 설계서 §1.2.

A는 단일 에이전트와 고성능 모델 고정 기준선, B는 단일 에이전트에서 단계별 모델 전환, C는 멀티 에이전트에 같은 고성능 모델 배정, D는 역할과 복잡도에 따른 적응형 이기종 멀티 에이전트 배치다. B의 단계 전환과 D의 적응형 배치는 같지 않으므로 엄밀한 2×2 요인 실험으로 해석하지 않는다. D가 모든 역할을 동시에 실행한다는 뜻이 아니다. 모델별 실제 API 단가를 기록하며 동일 단가라고 가정하지 않는다. 구독형 도구는 참고군으로 별도 기록한다. 실패 호출 및 판정·계획 비용도 합산한다. 출처: 사용자 최종 승인 문구 §08, 보고서 §5.1.
