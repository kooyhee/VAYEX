비용 최적화 파이프라인

4단계 토큰 압축 및 캐시 극대화 구조

도구 출력 축약, 2-트랙 분기, 세션 모델 고정, 캐시 단가 계산의 4단계 파이프라인을 구축합니다.

단계 01 · 로컬 전처리

도구 출력 결과 압축

ANSI 제어 문자 스트립 및 연속 동일 행(빌드·테스트 반복 로그) 축약

에러 트레이스는 온전히 보존하여 진단 품질을 유지하고, 불필요한 컨텍스트 토큰 누적을 방지합니다.

단계 02 · 오버헤드 제거

규칙 기반 2-트랙 플래너

정규식·키워드 기반 정적 판정 (direct_execute vs survey_and_plan)

단순 코드 수정은 고비용 LLM 판정·계획 호출을 완전히 생략해 조율 비용과 응답 지연을 제거합니다.

단계 03 · 캐시 적중 극대화

세션 모델 고정 및 접두사 안정화

동일 세션 내 모델 유지(SESSION_MODEL_CACHE) 및 고정 시스템 프롬프트

공급자 측 KV 프롬프트 캐시 적중률을 유도하여 다중 턴 작업 시 후속 턴 입력 비용을 절감합니다.

단계 04 · 비용 정밀 집계

캐시 읽기 단가 반영 비용 계산

입력, 출력, 캐시 적중(Cache Read) 요율을 분리 적용 (calculateUsageCost)

공급자별 캐시 할인율(최대 90% 할인)을 반영한 실제 API 지출액을 정밀하게 모니터링합니다.

정적 규칙으로 조율 오버헤드를 없애고, 세션 모델 고정으로 클라우드 공급자의 KV 프롬프트 캐시 할인을 유도합니다.
